## 📋 就活ES（エントリーシート）

### 1. 自己PR作成

```
あなたは採用担当者です。
私の経験と強みを整理し、300字以内の自己PRを作成してください。
【経験】{ここに経験を書く}
【強み】{ここに強みを書く}
【志望業界】{業界名}
```

### 2. ガクチカ（学生時代に力を入れたこと）

```
{活動内容}を400字でまとめてください。
以下の観点を含めてください：
- 取り組んだ背景
- 具体的な行動
- 直面した困難とその克服方法
- 得られた学び
- それが今後のキャリアにどう活きるか
```

### 3. 志望動機テンプレート

```
以下のフォーマットで志望動機を350字で作成してください。
【志望企業】{企業名}
【自分のスキル】{スキル}
【企業の魅力】{魅力に感じる点}
→ 「企業の強み × 自分のスキル × 未来の貢献」の流れで書く
```

### 4. ES全体のブラッシュアップ

```
以下は私が書いたエントリーシートです。
採用担当者目線で改善点を指摘し、修正案を提示してください。
また、このESが通過する確率を％で評価してください。

{ES全文を貼り付け}
```

### 5. 逆質問リスト生成

```
{企業名}の{職種}を受ける予定です。
面接の最後に聞くべき逆質問を10個提案してください。
- 仕事内容に関する質問:3つ
- キャリアパスに関する質問:3つ
- 企業文化に関する質問:2つ
- 評価基準に関する質問:2つ
```

## 🎤 面接対策

### 6. 模擬面接（一般）

```
あなたは{業界}の採用面接官です。
以下の職種の面接をシミュレーションしてください。
【職種】{職種}
【私の経歴】{経歴}
1問ずつ質問し、私の回答に対してフィードバックをください。
```

### 7. 想定質問リスト

```
{業界}の{職種}の新卒/中途面接でよく聞かれる質問を20個リストアップし、
それぞれの意図と模範解答のポイントを教えてください。
```

### 8. ケース面接対策

```
{業界}のケース面接対策をしてください。
以下の観点で練習問題を1問出題し、解法のフレームワークを教えてください。
- フェルミ推定
- 事業戦略
- マーケット分析
```

### 9. 自己分析ワーク

```
私のこれまでの経験から、強みと弱みを客観的に分析してください。
【経験リスト】
{経験1}
{経験2}
{経験3}

また、これらの分析結果を面接でどう伝えるべきかアドバイスください。
```

### 10. 志望度の伝え方

```
{企業名}に対して「なぜ他社ではなく当社なのか」を説得力を持って伝えるための
回答スクリプトを3パターン（熱意型/論理型/共感型）作成してください。
```

### 11. ES添削（複数バージョン）

```
以下のESを3つの異なる方向性でリライトしてください：
1. リーダーシップ重視版
2. チームワーク重視版
3. 課題解決能力重視版

{ES全文}
```

### 12. 集団面接対策

```
集団面接での立ち回り方を教えてください。
私のタイプは{慎重/積極的/分析的}です。
- 発言のタイミング
```
