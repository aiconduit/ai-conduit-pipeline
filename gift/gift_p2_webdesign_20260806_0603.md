# 🤖 AI Conduit 無料プレゼント
## 【GCC 15行ルール完全対策】AI生成CSS/Figmaコードの「人的貢献」を証明する実践チートシート

動画で解説した「GCCが15行以上のAI生成コードを拒否」する新ルール。特にWebデザイン・UI/UX分野では、FigmaプロンプトやCSS生成をAIに頼る開発者が多いはず。**このルールを逆手に取り、「AI生成コード + 人間の検証・修正」をセットで記録する習慣**を今すぐ作りましょう。

---

## ✅ 5つの実践ルール（今日から適用可能）

### 1. 「15行ルール」を回避するコード分割術
- **1ブロック = 14行以下**に分割し、各ブロックに「人間による意図コメント」を追加
- 例: `/* ヒーローセクション: モバイルファーストで中央寄せ */`
- **ポイント**: コメントが「あなたの設計判断」の証拠になります

### 2. コミットメッセージでAI使用を明示
```
feat: ナビゲーションバーを追加 (AI生成 + 人間によるアクセシビリティ修正)
```
- これを習慣化するだけで、**法的な「重要な寄与」の記録**になります

### 3. CSS変数を活用した「人間設計の証拠」作り
```css
:root {
  --primary-color: #4F46E5; /* ブランドガイドラインより */
  --spacing-unit: 8px; /* 8pxグリッドシステム採用 */
}
```

### 4. AI生成コードの「人間検証リスト」を保存
- GitHubリポジトリに `AI_CODE_REVIEW.md` を作成し、以下を記録:
  - 生成日時・使用ツール（例: Claude 3 Opus / Figma AI）
  - 人間による変更点（例: コントラスト比をWCAG AA準拠に修正）

### 5. Figmaプロンプトに「人間の制約」を追加
```
NG: 自動レイアウトのみで完結させる
OK: 各コンポーネントに「デザイン意図」を箇条書きで追加
```

## 🎨 すぐ使えるFigmaプロンプト（5選）

### プロンプト1: デザインシステム自動生成
```
あなたはシニアUIデザイナーです。
以下を生成してください:
- 8pxグリッドのカラーパレット（プライマリ/セカンダリ/アクセント）
- 各色のWCAG 2.1 AAコントラスト比の計算結果
- 人間が後で調整するための「デザイントークン」候補
※必ず「人間によるレビュー項目」を最後に3つ列挙してください
```

### プロンプト2: レスポンシブCSS生成（14行制限付き）
```
モバイルファーストのナビゲーションバーCSSを生成してください。
条件:
- 1ブロックは14行以内に分割
- 各ブロックに「人間が確認すべきポイント」をコメントで追加
- ブレークポイントは768pxと1024px
```

### プロンプト3: アクセシビリティ監査
```
以下のCSSをWCAG 2.1 AAに準拠するよう修正してください。
修正点ごとに「なぜこの変更が必要か」を1行コメントで追加。
修正後のコードは14行ずつに分割してください。
```

### プロンプト4: コンポーネント設計
```
Figmaで使用するボタンコンポーネントの設計仕様を生成:
- 通常/ホバー/アクティブ/フォーカス状態のCSS
- 状態ごとのカラーコード（コントラスト比付き）
- 人間が最終決定するための「デザイン判断メモ」を末尾に追加
```

### プロンプト5: コードレビュー支援
```
このCSSファイルをレビューしてください。
- 14行以上のAI生成ブロックを検出
- 各ブロックに「人間の関与が必要な理由」を付与
- 修正提案は1ブロック14行以内で
```

## 🛠️ 推奨ツール（2024年12月時点）

- **Figma AI**: `Shift + I` でプロンプト入力 → デザイン生成
