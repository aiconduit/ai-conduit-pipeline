# Claude Codeモバイルで外出先からコーディング - 実践テンプレート

## この動画で学んだこと
Claudeアプリの「Code」タブを使えば、外出先からでもスマートフォンでコードレビューやPR承認などの開発タスクを完結できます。PCがなくても、モバイルだけで開発フローに参加できるのが最大の利点です。

### 1. Claudeアプリのインストール（初回セットアップ）

```bash
# iOSの場合: App Storeで「Claude」を検索してインストール
# Androidの場合: Google Play Storeで「Claude」を検索してインストール

# インストール後の初期設定

# 2. Anthropicアカウントでログイン（または新規作成）

```

### 2. モバイルでのコードレビュー手順

```markdown
# モバイルでのコードレビューチェックリスト

## レビュー時の確認項目
- [ ] 変更の意図がコミットメッセージに明確に記載されているか
- [ ] コードスタイルがプロジェクトの規約に準拠しているか
- [ ] テストが追加・更新されているか
- [ ] 破壊的変更がないか（または適切にドキュメント化されているか）

## モバイルでのPR承認フロー
1. Claudeアプリを開く
2. 左側の「Code」タブをタップ
3. レビュー対象のPRを選択
4. 変更内容を確認（差分表示で確認可能）
5. コメントを追加 or 承認ボタンをタップ
```

### 3. モバイル開発用の便利なプロンプト例

```text

- セキュリティ上の問題
- パフォーマンスへの影響
- コードの可読性
- テストの網羅性

# リファクタリング用プロンプト
このコードをより保守しやすい形にリファクタリングしてください。
改善点と理由も説明してください。
```

### 4. モバイル開発のためのGitコマンド（ターミナル使用時）

```bash
# モバイル端末でターミナルを使う場合（iOS: a-Shell, Android: Termux）

# PRの確認
gh pr list
gh pr view <PR番号>

# 変更の確認
git fetch origin
git diff origin/main...HEAD

# レビューコメントの追加
gh pr review <PR番号> --comment "LGTM! ただし、テストケースを追加してください。"

# PRの承認
gh pr review <PR番号> --approve
```

## 使い方

1. **初回セットアップ**: App StoreまたはGoogle Play StoreでClaudeアプリをインストールし、Anthropicアカウントでログインします
2. **Codeタブへのアクセス**: アプリを開いたら左側のナビゲーションから「Code」タブを選択します
3. **リポジトリの連携**: GitHubやGitLabなどのリポジトリを連携し、アクセス権限を設定します
4. **レビューフロー**: 通知が来たらCodeタブから該当PRを開き、変更内容を確認してコメントや承認を行います
5. **緊急時の対応**: 外出先でバグ報告を受けた場合も、モバイルから即座にコードを確認し、修正方針をチームに共有できます

## よくある質問

**Q: モバイルアプリでコードを編集することはできますか？**
A: はい、ClaudeアプリのCodeタブから直接コードの編集が可能です。ただし、複雑なリファクタリングよりは、簡単な修正やレビューコメントの追加に適しています。大規模な変更はPCでの作業を推奨します。

**Q: オフラインでも使えますか？**
A: 基本的にオンライン環境が必要です。ただし、Claudeアプリはキャッシュ機能があるため、直前に開いたファイルや会話はオフラインでも閲覧できます。

**Q: セキュリティ面での注意点はありますか？**
A: モバイル端末での開発作業には以下の点に注意してください：
- 生体認証（Face ID / 指紋認証）を必ず有効にする
- 公共Wi-FiではVPNを使用する
- 機密情報を含むコードはモバイルで開かない
- アプリの自動ロックを設定する

**Q: 複数のリポジトリを管理できますか？**
A: はい、複数のGitHub/GitLabアカウントやリポジトリを連携できます。Codeタブ内でリポジトリを切り替えて作業できます。
