# Claude Codeモバイルで外出先からコーディング - 実践テンプレート

## この動画で学んだこと
Claudeアプリの「Code」タブを使えば、外出先からスマートフォンだけでコードレビューやPR承認などの開発業務を完結できます。PCがなくても、モバイルで開発フローを止めない方法を解説します。

## すぐに使えるテンプレート

### 1. モバイルセットアップチェックリスト

```markdown
# モバイル開発環境セットアップ

## 事前準備
- [ ] App Store / Google Play で「Claude」アプリをインストール
- [ ] Claudeアプリにログイン（アカウント連携）
- [ ] GitHub / GitLab との連携を確認
- [ ] プッシュ通知を有効化（PR承認・レビュー依頼の通知用）

## モバイルでできること
- [ ] コードレビュー（コメント・承認）
- [ ] PRのマージ判断
- [ ] Issueの確認・コメント
- [ ] コミット履歴の確認
- [ ] 簡単なコード修正（Claude Code経由）
```

### 2. モバイルでのPRレビューフロー

```bash
# モバイル版Claude Codeでの実行例（プロンプト）

# 1. レビュー対象のPRを確認
"今日アサインされたPRの一覧を表示して"

# 2. 特定PRの詳細を確認
"PR #123の変更内容を要約して、問題点があれば指摘して"

# 3. コードレビューコメントを生成
"PR #123のsrc/app.tsの変更に対して、型安全性の観点からレビューコメントを3つ提案して"

# 4. 承認・却下の判断
"PR #123の変更はLGTMです。承認コメントを英語で投稿して"
```

### 4. モバイルワークフロー最適化設定

```yaml
# .claude/settings.json - モバイル用設定
{
  "mobile": {
    "enabled": true,
    "quickActions": [
      {
        "name": "PRレビュー",
        "prompt": "アサインされたPRをレビューし、承認/却下の判断をしてください",
        "icon": "review"
      },
      {
        "name": "進捗報告",
        "prompt": "今日の作業進捗を箇条書きでまとめてください",
        "icon": "progress"
      },
      {
        "name": "緊急対応",
        "prompt": "直近のコミットを確認し、緊急対応が必要な問題を特定してください",
        "icon": "alert"
      }
    ],
    "notifications": {
      "prAssigned": true,
      "reviewRequested": true,
      "mergeConflict": true

  }

```

### 5. モバイル×デスクトップ連携テンプレート

```markdown
# モバイル⇔デスクトップ連携メモ

## 外出先でできること（モバイル）
1. PRの一次レビュー（コメント・承認）
2. 緊急Issueのトリアージ
3. 進捗確認・チームへの共有
4. 軽微なコード修正（Claude Code経由）

## 帰社後にやること（デスクトップ）
1. モバイルで作成したレビューコメントの最終確認
2. 複雑なリファクタリング対応
3. マージ後のテスト実行
4. 詳細なコードレビュー（モバイルで指摘した内容の深掘り）

## 連携のコツ
- モバイルでは「判断」と「指示」を中心に行う
- 詳細な実装はデスクトップで行う
- レビューコメントはモバイルで作成し、デスクトップで最終確認
```

## 使い方

1. **セットアップ**: App Store / Google Play でClaudeアプリをインストールし、ログインします
2. **連携確認**: GitHub/GitLabとの連携を設定し、リポジトリへのアクセス権を確認します
3. **クイックアクション設定**: 上記のsettings.jsonを`.claude`フォルダに配置して、モバイル用のクイックアクションを有効にします
4. **プロンプト活用**: テンプレートのプロンプトをコピーして、ClaudeアプリのCodeタブで実行します
5. **通知設定**: PRアサインやレビュー依頼の通知をオンにして、見逃しを防ぎます

## よくある質問

**Q: モバイルでコードを書くことはできますか？**
A: はい、Claude Code経由で簡単なコード修正や生成が可能です。ただし、複雑なリファクタリングや大規模な編集はデスクトップでの作業をおすすめします。モバイルは「レビュー・判断・指示」を中心に活用しましょう。

**Q: オフラインでも使えますか？**
A: Claudeアプリは基本的にオンライン環境が必要です。オフライン時は、事前にダウンロードしたリポジトリの閲覧や、作成済みのメモ確認程度が可能
