#### 1. Figmaプロンプト：STE-100準拠UIテキスト生成
```
あなたは航空宇宙規格STE-100のエキスパートです。
以下のUIテキストをSTE-100準拠に書き換えてください。

- 受動態は使わない
```

#### 3. AI校正プロンプト：技術英語チェックリスト
```
以下の技術文書をSTE-100規格で校正してください。
チェック項目：
1. 許容語彙リストにない単語を検出 → ■でマーク
2. 1文が21語以上 → 赤字で警告
3. 受動態 → 黄色でハイライト
4. 略語の初出定義漏れ → 青で指摘
5. 修正提案を表形式で出力

対象テキスト：
[ここに校正したい英文を貼り付け]
```

#### 4. Figma変数：グローバルUIトークン
```
Figma Variablesとして以下を定義：

- text/primary/en: "Save Changes" (16px/500)
- text/primary/ja: "変更を保存" (16px/500)
- button/confirm/en: "Confirm" (14px/600)
- button/confirm/ja: "確認" (14px/600)
- error/message/en: "Enter a valid email address" (14px/400)
- error/message/ja: "有効なメールアドレスを入力してください" (14px/400)

※文字数が異なるため、ja/enでレイアウトが崩れないよう
  オートレイアウトのmin/max幅を設定すること。
```

#### 5. CSSグリッド：多言語対応レイアウト
```css
/* 英語・日本語の文字数差に対応するグリッド */
.lang-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
  padding: 16px;
}

/* 英語表示時の文字詰め最適化 */
html[lang="en"] .lang-grid {
  font-size: 15px;
  letter-spacing: 0.01em;
}

/* 日本語表示時の行間調整 */
html[lang="ja"] .lang-grid {
  font-size: 14px;
  line-height: 1.8;
}
```
