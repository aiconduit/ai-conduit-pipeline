# Claude Code の disallowed で不要な書き込み消滅 - 実践テンプレート

## この動画で学んだこと
エージェントの設定ファイルに **`disallowedTools`** を追加するだけで、レビュー時に不要なツール呼び出しを書き込みから除外できるようになります。

## すぐに使えるテンプレート
以下の内容を **`review_agent.yaml`**（任意の名前でも可）として保存してください。  
※ファイルの先頭にある `---` から `---` までが **Front‑Matter** です。  
```yaml
---
# -------------------------------------------------
# Claude Code 用 エージェント設定ファイル
# -------------------------------------------------
# このエージェントはコードレビュー専用です。
# disallowedTools に列挙したツールは、プロンプト内で
# 使用されても出力に含められません（＝書き込みが消滅します）。
# -------------------------------------------------
name: review-agent
description: "コードレビュー専用エージェント（不要ツール除外）"
model: claude-3-5-sonnet-20241022   # 例: 使用する Claude のバージョン
temperature: 0.0
max_output_tokens: 4000

# ★ ここからがポイント ★
# disallowedTools に除外したいツール名を列挙してください。
# 例: `bash`, `python`, `git` など
disallowedTools:
  - bash          # シェルコマンドの実行を禁止
  - python        # Python スクリプトの実行を禁止
  - git           # Git 操作を禁止
  - curl          # ネットワーク呼び出しを禁止
  - wget          # 同上

# 必要に応じて他の設定も追記できます
# system_prompt: |
#   あなたはコードレビューエージェントです。...
---
# ここからはエージェント本体の設定（例としてシンプルに記載）
# 実際に Claude に渡す JSON 形式のペイロードは
# 上記 Front‑Matter を除いた部分がそのまま使用されます。
# -------------------------------------------------
{
  "name": "{{name}}",
  "description": "{{description}}",
  "model": "{{model}}",
  "temperature": {{temperature}},
  "max_output_tokens": {{max_output_tokens}},
  "disallowedTools": {{disallowedTools}}
}
```

## 使い方
1. **ファイル保存**  
   上記コードを `review_agent.yaml`（または好きな名前）として保存します。

2. **Claude Code に読み込ませる**  
   - Claude Code の UI で「エージェント作成」→「設定ファイルからインポート」を選択。  
   - 先ほど保存した `review_agent.yaml` をアップロードします。

3. **レビュー実行**  
   - 作成したエージェントを選択し、レビューしたいコードやプルリクエストを入力。  
   - `bash` や `python` など、 `disallowedTools` に列挙したツールは出力に現れず、不要な書き込みが自動で消滅します。

4. **必要に応じてカスタマイズ**  
   - 除外したいツールが増えたら `disallowedTools` に追記。  
   - `system_prompt` など他の設定も同様に Front‑Matter に追加可能です。

## よくある質問

**Q1. `disallowedTools` に指定できるツール名はどこで確認できますか？**  
A: 現在は Claude Code が公式にサポートしているツール名（例: `bash`, `python`, `git`, `curl`, `wget`）を文字列で列挙します。公式ドキュメントやエージェント作成画面のツール一覧を参照してください。

---

**Q2. すでに書き込み済みのコードに対して後から `disallowedTools` を適用できますか？**  
A: 既存の出力は自動で削除されません。**再度**エージェントを実行し直すことで、除外設定が反映された新しい出力が得られます。

---

**Q3. `disallowedTools` に何も入れないとどうなりますか？**  
A: デフォルトでは全ツールが使用可能です。空リスト `[]` を設定すれば、すべてのツール呼び出しが禁止されます（実質的にツールなしの純粋テキスト生成になります）。

---

**Q4. 設定ファイルの構文エラーが出たときは？**  
A: YAML のインデントはスペース2個が推奨です。エラーメッセージに示された行番号を確認し、`-` の前後や `:` の後に余計な文字が入っていないかチェックしてください。

---

**Q5. 他のエージェントと同時に使うことはできますか？**  
A: 可能です。エージェントは名前で識別されるので、別名で別ファイルを作成すればそれぞれ独立して動作します。

---

**Q6. `disallowedTools` に指定したツールが実際に呼び出されているか確認したい**  
A: エージェント実行後のログに「Tool invoked: <tool_name>」というメッセージが出ます。除外されたツールはこのメッセージが出ず、出力にも現れません。

---

**Q7. 日本語コメントが必要な場合はどうすれば？**  
A: 上記テンプレートはすでに日本語コメント付きです。必要に応じて `#` で始まる行を増やしてコメントを追記してください。

---

**Q8. 設定ファイルを Git 管理したい**  
A: `review_agent.yaml` をリポジトリにコミットすれば、チーム全員が同じ設定でエージェントを利用できます。機密情報（API キー等）は別途 `.env` などで管理してください。
