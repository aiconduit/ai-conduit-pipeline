### 🎯 2. 要件分解プロンプト（コピペで即使用）

```
あなたはシニアソフトウェアアーキテクトです。
以下の要件を5段階で分解してください：

【要件】{ここにやりたいことを記入}

出力形式：
1. **機能要件** - 実装すべき機能のリスト
2. **非機能要件** - パフォーマンス・セキュリティ等
3. **データモデル** - 必要なテーブル/型定義
4. **API設計** - エンドポイント/関数シグネチャ
5. **実装順序** - 依存関係を考慮したステップ

制約：
- 各項目に具体的なファイル名・関数名を含める
- 見積もり時間も記載
- リスクと対策も明記
```

### 💻 3. 超効率AIコーディングプロンプト集

```

「{機能名}の実装計画を立ててください。
以下の観点で設計書を作成：

```

```bash
claude --agent "reviewer" "生成されたコードをレビューし改善点を指摘"
```

### 🔧 6. 実践テンプレート：タスク分解プロンプト

```
以下のタスクを分解してください：

タスク: "{ここにタスクを記述}"

分解手順：
1. タスクを3-5つのサブタスクに分割
2. 各サブタスクに優先度を設定（P0/P1/P2）
3. 依存関係を図示
4. 見積もり時間を計算
5. リスクを洗い出し

出力は以下の形式：
📋 タスク分解結果
├─ P0: サブタスク名（見積もり: X時間）
│   └─ 依存: なし
├─ P1: サブタスク名（見積もり: Y時間）
│   └─ 依存: P0-1
└─ P2: サブタスク名（見積もり: Z時間）
    └─ 依存: P1-2

⚠️ リスク:
- リスク1: 対策
- リスク2: 対策
```
