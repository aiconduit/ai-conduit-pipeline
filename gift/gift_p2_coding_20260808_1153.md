### ✅ 1. プロジェクト全体の文脈を与える「マスタープロンプト」

Codexにプロジェクト構造を理解させるための最初の一撃です。

```
あなたはシニアフルスタックエンジニアです。
以下の技術スタックで、ベストプラクティスに従ったコードを生成してください。
- 言語: TypeScript (strictモード)
- フレームワーク: Next.js 14 (App Router)
- スタイリング: Tailwind CSS v4
- テスト: Vitest + React Testing Library
- パッケージ管理: pnpm
要件:
1. 型安全性を最優先する
2. エッジケースを考慮する
3. パフォーマンス最適化のコメントを残す
```

### ✅ 2. コードレビュー自動化プロンプト

生成されたコードを**セキュリティ・保守性・パフォーマンス**の観点でレビューさせます。

```
以下のコードをレビューしてください。
各指摘事項に「重要度(高/中/低)」と「修正後のコード」を含めてください。
チェック項目:
- SQLインジェクションやXSSなどのセキュリティリスク
- 時間計算量・空間計算量
- DRY原則に反する重複コード
- エラーハンドリングの欠如
- 可読性の改善ポイント
```

### ✅ 6. oh-my-codex 必須コマンド集

**インストールから活用までの3つのコマンド**をすぐ使える状態に。

```bash
# 1. oh-my-codexのインストール（npm）
npm install -g oh-my-codex

# 2. Codexエイリアスの有効化
codex alias add oh-my-codex

# 3. プロンプト改善を有効化して起動
oh-my-codex --improve
```

> 💡 **ポイント**: 毎回プロンプトを書く前に `--improve` フラグを付けるだけで、  
> 自動的にプロンプトが最適化され、**回答精度が平均2.3倍向上**します。

### ✅ 10. 緊急時トラブルシューティング一覧

| 症状 | 解決コマンド |
|------|------------|
| Codexが応答しない | `Ctrl+C` → `codex reset` |
| プロンプトが改善されない | `oh-my-codex --config` で設定確認 |
| Copilotの補完が消えた | `:Copilot disable` → `:Copilot enable` |
| 生成コードが重複する | `codex session clear` で履歴リセット |
