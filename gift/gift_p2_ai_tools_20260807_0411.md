### ✅ その1: エラー解決を30秒に短縮する「超速デバッグ術」

**動画で紹介した裏技①：** エラーが出たらコピペ不要！`gemini -i`で直接相談

```bash
# 直前のエラーをそのままGeminiに丸投げする（最強コマンド）
gemini -i "このエラーを解決する方法を教えて。原因と修正コードをセットで出力して"

# さらに便利！エラーログをファイルに保存して、ファイルごと投げる
npm run build 2>&1 | tee error.log
gemini -i "error.logを読んで、エラーの原因と修正手順を教えて"
```

**おまけ：エラー解決プロンプトテンプレート（コピペ用）**

```
あなたはシニアエンジニアです。以下のエラーを解決してください。
1. エラーの根本原因を簡潔に
2. 修正後のコードを完全な形で
3. 修正手順をステップバイステップで
※日本語で回答してください
```

### ✅ その2: ファイル操作を自然言語で指示する「AIファイルマネージャー術」

**動画で紹介した裏技②：** ファイル操作もチャット感覚で！

```bash
# ファイルの中身を要約させる
gemini -i "src/ 配下の全ファイルを分析して、このプロジェクトの構造と役割をまとめて"

# 複数ファイルを一括リファクタリング
gemini -i "src/utils/ にある関数をすべてTypeScriptで型安全になるよう修正して"

# ファイルを読み込んでレビュー
gemini -i "app.py を読んで、セキュリティ上の問題点とパフォーマンス改善点を指摘して"
```

**超実践テク：** ファイルを直接参照させる「@」構文

```bash
# @ファイル名 で特定ファイルを参照できる（VSCodeの拡張機能使用時）
gemini -i "@src/main.py のコードをレビューして、バグを探して"
```

### ✅ その3: コード生成を加速する「超優秀ペアプロ術」

**動画で紹介した裏技③：** コメントに「AI」と書けば無料プレゼントゲット！

```bash
# 要件からコードを即生成
gemini -i "PythonでCSVファイルを読み込んで、列ごとの平均値を出力するスクリプトを作って"

# コードの説明を自動生成

# テストコードも自動生成
gemini -i "この関数のユニットテストをpytestで作成して。エッジケースもカバーして"
```

### ✅ その4: 【必見】Gemini CLIの設定を最適化する裏ワザ

```bash
# モデルを指定して高精度回答を得る
gemini -i "..." --model gemini-2.0-pro

# 出力形式を指定してMarkdownで受け取る
gemini -i "..." --output-format markdown

# 履歴をリセットしてクリーンな状態で質問
gemini -i "..." --reset

# プロンプトをファイルから読み込む（長文プロンプトに最適）
gemini -i "$(cat prompt.txt)"
```

### ✅ その5: 最強の組み合わせ「プロフェッショナルプロンプト集」

| 用途 | プロンプト（コピペ用） |
|------|------------------------|
| **コードレビュー** | `このコードの可読性・保守性・パフォーマンスの観点でレビューして。改善案を具体的に` |
| **バグ修正** | `このコードの潜在的なバグを3つ挙げて、それぞれの修正コードを示して` |
| **リファクタリング** | `この関数をより簡潔で効率的なコードにリファクタリングして。変更点も説明して` |
| **学習用** | `このコードの各処理が何をしているか、初心者向けにコメント付きで解説して` |
| **ドキュメント生成** | `このコードのREADMEを日本語で作成して。使用方法と注意点を含めて` |

### 🎁 ボーナス：Gemini CLIインストール＆初期設定

```bash
# インストール（Node.jsが必要）

# 初期設定
gemini setup

# バージョン確認
gemini --version

# ヘルプ確認
gemini --help
```
