# Claude Codeで自動レビューAIを安全に！ - 実践テンプレート

## この動画で学んだこと
Claude Code のサブエージェント機能を使って、コードレビュー専用の AI エージェントを作成し、**Write** と **Edit** ツールの使用を禁止することで安全に自動レビューを実行できます。

---

## すぐに使えるテンプレート  

以下の内容をそのままコピーして、プロジェクトのルートに **`.claude/agents/reviewer.md`** という名前のファイルを作成してください。

```yaml
# .claude/agents/reviewer.md
# -------------------------------------------------
# Claude Code 用サブエージェント: reviewer
# -------------------------------------------------
# このエージェントはコードレビュー専用です。
# Write, Edit ツールは使用できないように制限しています。
# -------------------------------------------------

name: reviewer               # エージェントの識別子
description: >-             # 任意の説明（省略可）
  コードレビュー専用エージェント。Write/Edit ツールは使用不可。

# -----------------------------------------------------------------
# 使用禁止ツールの指定
# -----------------------------------------------------------------
disallowedTools:
  - Write
  - Edit

# -----------------------------------------------------------------
# 追加の設定（必要に応じてカスタマイズしてください）
# -----------------------------------------------------------------
# 例: 何らかのカスタムプロンプトを付与したい場合
# prompt: |
#   あなたはプロのコードレビュアーです。以下のコードをレビューし、問題点と改善案を箇条書きで出力してください。
```

> **ポイント**  
> - `name` はエージェントを呼び出す際のキーです。  
> - `disallowedTools` に列挙したツールは、エージェントが実行時に利用できなくなります。  
> - 必要に応じて `description` や `prompt` を追記して、エージェントの振る舞いを調整できます。

---

## 使い方

1. **ファイルを作成**  
   ```bash
   mkdir -p .claude/agents
   cat > .claude/agents/reviewer.md <<'EOF'
   # (上記テンプレートを貼り付け)
   EOF
   ```

2. **Claude Code にエージェントを認識させる**  
   プロジェクトのルートで以下のコマンドを実行すると、エージェントがロードされます。  
   ```bash
   claude agents list   # 登録されているエージェント一覧に reviewer が表示されるはず
   ```

3. **自動レビューを実行**  
   任意のコードファイル（例: `src/main.py`）に対して reviewer エージェントを呼び出します。  
   ```bash
   claude code review --agent reviewer src/main.py
   ```
   - `--agent reviewer` で先ほど作成したエージェントを指定。  
   - エージェントは **Write** と **Edit** ツールを使用できないため、レビュー結果のみを出力します。

4. **結果を確認**  
   コマンド実行後、ターミナルにレビューコメントが表示されます。必要に応じてファイルにリダイレクトして保存できます。  
   ```bash
   claude code review --agent reviewer src/main.py > review_report.txt
   ```

## よくある質問

**Q1: `disallowedTools` に他のツールも追加したいです。**  
**A:** `disallowedTools` は YAML の配列形式で列挙できます。例えば `Search` も禁止したい場合は次のように書き足してください。  
```yaml
disallowedTools:
  - Write
  - Edit
  - Search
```

---

**Q2: エージェントが期待通りに動かないときはどうすればいいですか？**  
**A:**  
1. ファイルのインデントやスペースが正しいか確認（YAML はインデントが重要）。  
2. `claude agents list` でエージェントが正しく登録されているか確認。  
3. エラーメッセージが出る場合は、`claude --debug` オプションで詳細ログを取得し、問題箇所を特定してください。

---

**Q3: カスタムプロンプトを設定したいです。**  
**A:** `prompt` キーを追加し、マルチライン文字列 (`|` または `|-`) で指示を書き込めます。例:  
```yaml
prompt: |
  あなたは厳格なコードレビュアーです。コードの可読性、パフォーマンス、セキュリティ観点で問題点を指摘し、具体的な改善案を提示してください。
```

---

**Q4: エージェントを削除したいときは？**  
**A:** 該当ファイルを削除すれば自動的に無効化されます。  
```bash
rm .claude/agents/reviewer.md
```
その後、`claude agents list` で一覧から消えていることを確認してください。

---

**Q5: 複数のエージェントを同時に使うことはできますか？**  
**A:** 現在の Claude Code CLI では、1 回のコマンドで 1 エージェントしか指定できません。別々のコマンドで順次呼び出すか、エージェント内部で複数タスクをハンドリングするようにプロンプトを設計してください。
