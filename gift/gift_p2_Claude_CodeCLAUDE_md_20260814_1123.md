# Claude CodeのCLAUDE.mdで指示の手間がゼロになった - 実践テンプレート  

---  

## この動画で学んだこと  
- **CLAUDE.md** をプロジェクトのルートに置くだけで、Claude にコーディング規約やスタイルガイドを自動的に認識させられる。  
- 設定は **Markdown** 形式で記述でき、コメントもそのまま残すのでチーム全体で共有しやすく、指示ミスが激減する。  

---  

## すぐに使えるテンプレート  

### 1️⃣ `CLAUDE.md`（プロジェクトルートに配置）  

```markdown
# CLAUDE.md
# -------------------------------------------------
# このファイルは Claude に対してプロジェクト全体のコーディング規約・スタイルガイドを指示します。
# 以下の項目は必ず守ってください。守れない場合はエラーを返してください。

## コーディング規約
- **言語**: Python 3.11
- **インデント**: スペース 4 つ
- **行長**: 100 文字以内
- **文字コード**: UTF-8
- **型ヒント**: すべての関数・変数に型ヒントを付与すること
- **ドキュメンテーション**: Google style docstring を必ず記述

## 禁止事項
- `print` 文の使用はデバッグ時以外禁止
- グローバル変数の使用は原則禁止
- `TODO` コメントは残さない

## テスト方針
- `pytest` を使用し、カバレッジは 90% 以上を目指す
- テストファイルは `tests/` ディレクトリ以下に配置

## 例外的な指示
- データベースアクセスは `SQLAlchemy` の ORM を使用
- HTTP クライアントは `httpx` を使用し、非同期処理を推奨

# -------------------------------------------------
```

> **ポイント**  
> - 必要に応じてプロジェクト固有のルールを追記してください。  
> - Markdown の見出し (`##`) や箇条書きは Claude が自動で認識しやすい構造です。
