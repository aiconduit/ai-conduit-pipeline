## 1️⃣ STE100とは？3分でわかる基礎知識

**ASD-STE100（Simplified Technical English）** は、航空宇宙・防衛産業向けに開発された英語規格です。

| 項目 | 内容 |
|------|------|
| 制定機関 | ASD（航空宇宙・防衛産業協会） |
| 現在のバージョン | Issue 8（2021年3月発行） |
| 語彙数 | 約980語の承認語彙のみ使用可能 |
| 主な目的 | 非ネイティブ話者でも理解しやすい文章作成 |

**💡 重要な数字：**
- 文章の最大長：**20語**（1文あたり）
- 段落の最大長：**6文**
- 手順書の能動態使用率：**100%**

## 3️⃣ STE準拠チェックリスト（20項目）

### 📝 文章レベル

- [ ] 1文が**20語以内**である
- [ ] 段落が**6文以内**である
- [ ] 各文に**1つの情報**のみ含まれる
- [ ] 能動態を使用している（受動態は**10%未満**）
- [ ] 否定形は「do not」を使用している

### 📝 語彙レベル

- [ ] 承認語彙（**約980語**）のみを使用している
- [ ] 技術用語はSTE辞書で定義されている
- [ ] 同義語を使っていない（例：startのみ使用）
- [ ] 略語は初出時に定義している
- [ ] 数量詞は具体的な数字を使用している

### 📝 文法レベル

- [ ] 現在形を基本としている
- [ ] 命令形（手順書の場合）を使用している
- [ ] 冠詞（a/an/the）を適切に使用している
- [ ] 分詞構文を使っていない
- [ ] 関係代名詞（which/that）を最小限にしている

### 📝 フォーマット

- [ ] 箇条書きを効果的に使用している
- [ ] 警告・注意事項を適切に配置している
- [ ] 図表番号を明確にしている
- [ ] 用語集を設けている
- [ ] 指示語（this/these）の参照が明確である
