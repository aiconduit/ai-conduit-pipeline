# Claude Codeのフロントマター設定で危険なツール実行を阻止 - 実践テンプレート

## この動画で学んだこと
Claude Code では、プロジェクト直下の `.claude/frontmatter.md` に設定を書くだけで、外部ツールやシェルコマンドの実行を完全にブロックできます。  

## すぐに使えるテンプレート
以下の手順をそのままコピーして、ターミナルで実行してください。

```bash
# 1️⃣ .claude フォルダをプロジェクトのルートに作成
mkdir -p .claude

# 2️⃣ frontmatter.md を作成し、危険なツール実行を無効化する設定を書き込む
cat > .claude/frontmatter.md <<'EOF'
# -------------------------------------------------
# Claude Code Frontmatter
# -------------------------------------------------
# このファイルはプロジェクト全体に適用される
# 設定を記述します。下記のオプションで
# ツール（外部コマンド・シェル実行）を無効化します。
# -------------------------------------------------

---
# ツール実行を禁止するフラグ
allow_tool_execution: false   # ← ここを false にすると、Claude が外部ツールを呼び出すことができなくなります

# 必要に応じて他の安全設定もここに追加できます
# 例: 特定のファイルタイプだけを許可する等
# -------------------------------------------------
EOF
```

> **ポイント**  
> - `allow_tool_execution: false` がキーです。`true`（デフォルト）にするとツール実行が許可されます。  
> - YAML の区切りは `---` で始め、必ずインデントやスペースに注意してください。  

## 使い方
1. **プロジェクトのルートディレクトリに移動**  
   ```bash
   cd /path/to/your/project
   ```
2. **上記のテンプレートコマンドをそのまま貼り付けて実行**  
   これだけで `.claude/frontmatter.md` が作成され、Claude Code がツール実行をブロックします。  
3. **Claude Code でコード生成を開始**  
   生成されたコードは、外部コマンドが走らない安全な状態で提供されます。  

## よくある質問

**Q1: すでに `.claude` フォルダがある場合はどうすればいいですか？**  
A: `mkdir -p .claude` は既存のフォルダがあってもエラーになりません。そのまま実行してください。既存の `frontmatter.md` がある場合は、内容を上書きしたくないときはバックアップを取ってから上書きしてください。

---

**Q2: ツール実行だけでなく、特定のファイルへの書き込みも制限したいです。**  
A: 現在のフロントマター仕様では `allow_tool_execution` だけが公式に提供されています。将来的に追加設定が出たら同様に YAML に追記すれば対応できます。  

---

**Q3: 設定が反映されているか確認したいです。**  
A: Claude Code のログに「Tool execution disabled」や類似のメッセージが出れば有効です。実際に `!ls` などのシェルコマンドを含むプロンプトを送ってエラーになるかテストしてください。  

---

**Q4: 設定を元に戻したいときはどうすれば？**  
A: `frontmatter.md` の `allow_tool_execution` を `true` に変更するか、行自体を削除すれば元に戻ります。  

---

**Q5: 他のプロジェクトでも同じ設定を使いたいです。**  
A: 上記の `mkdir` と `cat` コマンドを各プロジェクトのルートで実行すれば OK です。スクリプト化しておくと便利です。
