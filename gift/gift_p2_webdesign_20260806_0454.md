## 🔥 なぜ今これが必要か？

## 1️⃣ AI生成コード宣言テンプレート

コードの先頭に必ず挿入する宣言コメント（15行以上のAI生成コードに適用）：

```css
/* ============================================================
   ⚠️ AI生成コード宣言
   - 生成ツール: Claude 3.5 Sonnet (2024年8月)
   - 生成日: 2024年8月20日
   - プロンプト数: 3回
   - 人間による修正箇所: レスポンシブ対応（2行）、カラー変数名（1行）
   - 著作権方針: 人間が修正・確認済み / ツール利用を記録
   ============================================================ */
```

```html
<!--
  このセクション（15行以上）はAI生成コードです。
  生成日: 2024-08-20 / ツール: GitHub Copilot
  レビュー担当: 山田太郎 / 承認日: 2024-08-21
-->
```

## 2️⃣ CSSコード品質チェックリスト（AI生成コード検収用）

AIが生成したCSSを受け入れる前に、この7項目をチェック：

- [ ] **カスタムプロパティ（CSS変数）** がハードコード値ではなく使用されているか
  ```css
  /* ❌ ハードコード */
  color: #3498db;
  
  /* ✅ 変数使用 */
  color: var(--primary-color);
  ```
  
- [ ] **メディアクエリのブレークポイント**が統一されているか（推奨: 480px / 768px / 1024px / 1440px）
- [ ] **クラス名**がBEM規約に従っているか（block__element--modifier）
- [ ] **!important** が使用されていないか（0回が理想）
- [ ] **ブラウザプレフィックス**（-webkit-, -moz-）が自動付与されているか
- [ ] **パフォーマンス**：アニメーションはtransform/opacityのみ使用か
- [ ] **アクセシビリティ**：色のコントラスト比が4.5:1以上か

## 4️⃣ AI生成コードのリファクタリング手順（5ステップ）

AIが生成したCSSを「人間のコード」として昇華させる手順：

### ステップ1: 変数抽出（5分）
```css
/* 修正前 */
.card { background: #f8f9fa; padding: 20px; border-radius: 8px; }
.btn { background: #007bff; padding: 10px 20px; border-radius: 8px; }

/* 修正後 */
:root {
  --color-bg-light: #f8f9fa;
  --color-primary: #007bff;
  --radius-md: 8px;
  --space-md: 20px;
  --space-sm: 10px 20px;
}
.card { background: var(--color-bg-light); padding: var(--space-md); border-radius: var(--radius-md); }
.btn { background: var(--color-primary); padding: var(--space-sm); border-radius: var(--radius-md); }
```

### ステップ2: 重複の排除（DRY原則）
### ステップ3: コメントで意図を記録（「なぜ」を残す）
### ステップ4: パフォーマンス最適化（unused CSS削除）
### ステップ5: アクセシビリティ検証（axe DevToolsでスキャン）

## 5️⃣ 著作権リスク回避のためのコーディング規約（社内用）

### 必須ルール5箇条

| ルール | 内容 | 違反時の対応 |
|--------|------|-------------|
| **ルール1** | 15行以上のAI生成コードはPRに「AI生成」タグ必須 | タグなしはレビュー拒否 |
| **ルール2** | AI生成コードの採用はレビュアー2名以上の承認が必要 | 承認記録をPRに残す |
| **ルール3** | プロジェクト内に「AI利用ログ.md」を作成し全AI利用を記録 | 更新なしはコミット拒否 |
| **ルール4** | ライセンス不明のコードは使用禁止（GitHub CopilotのPublic Codeモード禁止） | 使用発見時は即時削除 |
| **ルール5** | 生成AIの設定は「Suggestions matching public code: Block」に設定 | 設定確認を月次監査 |

### コマンドで設定確認（VS Code）

```json
// .vscode/settings.json
{
  "github.copilot.advanced": {
    "debug.useVulkan": false,
    "debug.showInlineValues": true,
    "debug.terminal": true
  },
  "github.copilot.enable": {
    "*": true,
    "yaml": false,
    "plaintext": false
  }
}
```

## 6️⃣ AI生成コード検出ツールリスト（レビュー時に使える）

### 無料ツール（2024年8月時点）

| ツール名 | 特徴 | コマンド |
|---------|------|----------|
| **GPTZero** | テキスト検出（コード対応） | Webアプリ |
| **CodeQL** | セキュリティ分析（AI生成コードの脆弱性検出） | `codeql database create` |
| **ESLint + eslint-plugin-ai** | AI生成コードのパターン検出 | `npx eslint . --rule 'ai/no-hardcoded'` |
| **git diff --stat** | AI生成コードのコミットサイズ確認 | `git log --stat` |
| **tiktoken** | トークン数計測（生成コードの規模推定） | `python -m tiktoken` |

### 検出コマンド例

```bash
# AI生成コードの特徴（過剰なコメント、無駄な変数）を検出
grep -r "Your task is to\|As an AI\|I'm sorry" --include="*.css" .

# 15行以上の新規追加コードを検出（GCC方針対応）
git diff HEAD~1 --numstat | awk '$1 > 15 {print $3}'
```
