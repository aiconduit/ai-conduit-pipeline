# Claude Codeのフロントマター設定で危険なツール実行を阻止 - 実践テンプレート

## この動画で学んだこと
Claude Code ではプロジェクトルートに `.claude/frontmatter.md` を置くだけで、危険な外部ツールの実行を一括で無効化できます。  

## すぐに使えるテンプレート
以下のコマンドと設定ファイルをそのままコピー&ペーストすれば、すぐに安全化が完了します。

```bash
# 1️⃣ プロジェクトのルートディレクトリに .claude フォルダを作成
mkdir -p .claude

# 2️⃣ frontmatter.md を作成し、下記内容を書き込む
cat > .claude/frontmatter.md <<'EOF'
---
# -------------------------------------------------
# Claude Code フロントマター設定
# -------------------------------------------------
# 危険なツール（シェルコマンド・外部プログラム等）の実行を無効化します。
# 必要に応じて安全と判断したツールだけを whitelist に列挙してください。
# -------------------------------------------------

# すべてのツール実行をデフォルトでブロック
disable_tool_execution: true

# 安全と判断したツールだけを許可（必要に応じて追加・削除）
allowed_tools:
  - python   # Python スクリプトの実行を許可
  - node     # Node.js スクリプトの実行を許可
  # - bash   # 例: bash を許可したい場合はコメントアウトを外す

# 追加の安全設定（任意）
# max_execution_time: 30   # ツール実行の最大時間（秒）を制限
# max_output_size: 1MB    # ツールからの出力サイズ上限

---
EOF
```

> **ポイント**  
> - `disable_tool_execution: true` がキーです。これだけで外部ツール呼び出しはすべてエラーになります。  
> - `allowed_tools` に列挙したツールだけが例外的に実行可能です。不要なツールはリストから外すか、リスト自体を削除してください。  
> - コメントは `#` で記述でき、Markdown のフロントマター（`---` で囲む）内でも有効です。

## 使い方
1. **フォルダとファイルを作成**  
   上記の `mkdir` と `cat` コマンドをターミナルで実行すると、`.claude/frontmatter.md` が自動生成されます。

2. **設定をカスタマイズ**  
   - デフォルトでブロックしたいツールがある場合は `allowed_tools` に追記。  
   - 実行時間や出力サイズの上限を設けたいときは、コメントアウトされた `max_execution_time` / `max_output_size` を有効化して数値を調整します。

3. **Claude Code を再起動**  
   設定を反映させるために、Claude Code（または VS Code の拡張機能）を再起動します。

4. **動作確認**  
   - 許可したツール（例: `python`）で簡単なスクリプトを実行し、正常に動くか確認。  
   - 許可していないツール（例: `bash`）で実行しようとすると、エラーが返ることを確認してください。

## よくある質問

**Q1: `allowed_tools` に何を入れればいいの？**  
A: Claude Code が内部で呼び出すツール名（例: `python`, `node`, `bash`, `git` など）を文字列で列挙します。許可したいツールだけを記載し、他はすべてブロックされます。

**Q2: すべてのツールをブロックしたいだけで、例外は不要です。**  
A: `allowed_tools` の項目を削除すれば、`disable_tool_execution: true` のみで全ツールが無効化されます。

**Q3: 設定が反映されない場合はどうすればいいですか？**  
A:  
1. `.claude/frontmatter.md` の構文エラーがないか確認（YAML のインデントや `---` の閉じ忘れに注意）。  
2. Claude Code を完全に再起動（VS Code のウィンドウを閉じて再度開く）。  
3. それでも解決しない場合は、拡張機能のバージョンが最新か確認し、必要ならアップデートしてください。

**Q4: `max_execution_time` や `max_output_size` は必須ですか？**  
A: 必須ではありません。デフォルトで無制限になるため、特に制限したい場合だけ設定してください。

**Q5: 他のプロジェクトでも同じ設定を使いたいです。**  
A: `.claude/frontmatter.md` をテンプレートとして保存し、各プロジェクトのルートにコピーすればすぐに適用できます。
