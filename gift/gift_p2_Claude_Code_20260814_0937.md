# Claude Codeで安全な自動コードレビュー – 実践テンプレート

## この動画で学んだこと
Claude Code のエージェントに **Write** と **Edit** のツール使用を禁止する設定を追加すれば、コードレビューだけに特化した安全な自動レビュー環境がすぐに構築できます。

---

## すぐに使えるテンプレート  

以下の内容をそのまま **.claude/agents/reviewer.md** というファイルに保存してください。  
（ディレクトリが存在しない場合は先に作成します）

```bash
# ディレクトリ作成（まだ無い場合だけ実行）
mkdir -p .claude/agents
```

```markdown
---
# エージェントの名前
name: reviewer

# 書き込み系ツールを禁止して、レビュー専用にする
disallowedTools:
  - Write
  - Edit
---

# reviewer エージェント用プロンプト
# -------------------------------------------------
# 目的: 提供されたコードの品質・セキュリティ・可読性を評価し、改善点を指摘する。
# 前提: 変更やファイル生成は行わない（disallowedTools で禁止）。
# 出力形式: Markdown の箇条書きで、問題点 → 推奨修正案 の形で提示する。

## 使い方例
```text
レビューしたいコードを貼り付けてください。

```markdown

- **SQLインジェクションのリスク**: `userInput` が直接クエリ文字列に結合されています。

### 推奨修正案

## 使い方

1. **ファイルを配置**  
   上記のコードブロックをコピーし、ターミナルで以下を実行して保存します。  

   ```bash
   cat > .claude/agents/reviewer.md <<'EOF'
   (ここに上記の Markdown 全文を貼り付け)
   EOF
   ```

2. **Claude Code にエージェントをロード**  
   Claude Code の UI か CLI で `reviewer` エージェントを選択します。  
   （例: `claude agents load .claude/agents/reviewer.md`）

3. **コードを貼り付けてレビュー**  
   エージェントに対してレビューしたいコードを送信すれば、  
   「Write」や「Edit」ツールが無効化されているため、**コードの変更は行わず**  
   問題点と改善案だけが返ってきます。

4. **結果を確認・適用**  
   提示された指摘を元に、手動でコードを修正してください。  
   必要に応じて別のエージェントやツールを併用して、実装作業を続けます。

## よくある質問

**Q1. `disallowedTools` に他のツールも追加したいです。**  
**A:** `disallowedTools` は YAML の配列で列挙できます。例:  

```yaml
disallowedTools:
  - Write
  - Edit
  - Browse
```

**Q2. エージェントが「Write」や「Edit」を呼び出そうとするとエラーになりますか？**  
**A:** はい、禁止されたツールを使用しようとすると Claude Code がエラーを返し、実行は中断されます。これにより安全性が保たれます。

**Q3. 既存の reviewer エージェントを上書きしたくない場合はどうすれば？**  
**A:** ファイル名を `reviewer_safe.md` などに変えて、ロード時にその名前を指定すれば別エージェントとして扱えます。

**Q4. 何か特別な権限設定は必要ですか？**  
**A:** `.claude/agents` ディレクトリとファイルに対して、実行ユーザーが読み取り権限を持っていれば問題ありません。  

**Q5. エージェントが返す出力形式を変更したいです。**  
**A:** `reviewer.md` のプロンプト部分（`# reviewer エージェント用プロンプト` 以下）を書き換えるだけで、出力フォーマットを自由にカスタマイズできます。
