# Claude Codeでコードレビューを自動化 - 実践テンプレート  

## この動画で学んだこと  
Claude Code のエージェント設定に `disallowedTools` を追加するだけで、**Write** と **Edit** の操作を禁止したコードレビュー専用エージェントをすぐに作れます。  

---

## すぐに使えるテンプレート  

### 1️⃣ `.claude/frontmatter` に設定を追加  

```yaml
# .claude/frontmatter
# -------------------------------------------------
# 既存の設定がある場合はそのまま追記してください
# -------------------------------------------------
agents:
  - reviewer   # ここで reviewer エージェントを有効化
```

> **ポイント**  
> - `agents:` 配列に `reviewer` を入れるだけで、後述の `reviewer.md` が自動的に読み込まれます。  
> - 既に他のエージェントが列挙されている場合はカンマで区切って追加してください。

---

### 2️⃣ `reviewer` エージェント定義ファイル  

**パス**: `.claude/agents/reviewer.md`  

```markdown
---
# .claude/agents/reviewer.md
# -------------------------------------------------
# Claude Code 用コードレビューエージェント
# -------------------------------------------------
name: reviewer               # ← エージェント名（必須）

# 書き込み系ツールを禁止して、レビューに専念させる
disallowedTools:            # ← ここから禁止ツールを列挙
  - Write
  - Edit

# 任意でプロンプトやシステム指示を追加可能
systemPrompt: |
  あなたはコードレビューの専門家です。以下の点に注意してレビューしてください。
  - コードの可読性
  - バグやロジックエラーの有無
  - ベストプラクティスへの適合
  - パフォーマンス上の問題
  - セキュリティリスク

# 日本語コメント付きで出力例を示す（必要に応じて削除可）
exampleOutput: |
  ### レビュー結果
  - **可読性**: 変数名が分かりやすく、関数分割も適切です。
  - **バグ**: `if (x = null)` が代入になっているのでバグです。`===` に修正してください。
  - **ベストプラクティス**: `await` の前に `try/catch` が無いので例外処理を追加してください。
```

> **ポイント**  
> - `name:` は必ず 1 行目に書く必要があります。  
> - `disallowedTools:` で **Write** と **Edit** を列挙すると、エージェントはコードの **書き換え** ができなくなります。  
> - `systemPrompt:` でレビュー方針を明示すると、出力が安定します。  

---

### 3️⃣ エージェントを有効化するコマンド（任意）  

```bash
# プロジェクトのルートで実行
claude agents enable reviewer
```

> **備考**  
> - 上記コマンドは `claude` CLI がインストールされている前提です。  
> - `frontmatter` にエージェント名が記載されていれば自動的に有効化されますが、手動で有効化したいときは上記コマンドを実行してください。  

---

## 使い方  

1. **プロジェクトのルートに `.claude` ディレクトリを作成**（既にある場合はスキップ）。  
2. 上記 **1️⃣** の内容を `.claude/frontmatter` に貼り付け、保存。  
3. **2️⃣** の内容を `.claude/agents/reviewer.md` として保存。  
4. 必要に応じて `claude agents enable reviewer` を実行し、エージェントを有効化。  
5. コードレビューを実行したいファイル／ディレクトリで以下のコマンドを実行（例）:  

   ```bash
   claude review ./src
   ```

   - エージェントが自動でレビューコメントを出力します。  
   - `Write` と `Edit` が禁止されているため、コードは一切変更されません。

## よくある質問  

**Q1: `disallowedTools` に他に指定できるツールはありますか？**  
**A:** 現在 Claude Code がサポートしているツールは `Write`, `Edit`, `Search`, `Run` などがあります。禁止したいツールを配列で列挙すれば同様に制限できます。  

---

**Q2: エージェントが期待通りに動かない場合はどうすればいいですか？**  
**A:**  
1. `.claude/frontmatter` に `agents:` 配列が正しく記載されているか確認。  
2. `reviewer.md` の `name:` が正しく `reviewer` になっているかチェック。  
3. CLI のバージョンが最新か `claude --version` で確認し、必要ならアップデート。  

---

**Q3: `systemPrompt` をカスタマイズしたいです。**  
**A:** `systemPrompt:` 以下に好きな指示を書き込めば OK です。日本語・英語どちらでも構いませんが、改行は `|` で始めるブロック文字列を使用してください。  

---

**Q4: エージェントが出力するレビュー結果をファイルに保存したいです。**  
**A:** 標準出力をリダイレクトすれば簡単です。  

```bash
claude review ./src > review_report.md
```

---

**Q5: 複数のエージェントを同時に有効化したいです。**  
**A:** `frontmatter` の `agents:` 配列にカンマ区切りで列挙すれば OK。例:  

```yaml
agents:
  - reviewer
  - tester
  - docgen
```
