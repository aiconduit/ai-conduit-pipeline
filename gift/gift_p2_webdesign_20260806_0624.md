### 📌 動画の核心：GCCの15行ルールとは？

> **GCC（GNU Compiler Collection）は、AI生成コードを15行以上受け入れると著作権侵害のリスクがあるとして正式に拒否方針を発表。**
> あなたがCopilotやChatGPTで生成したCSS・HTMLコードも、オープンソースプロジェクトでは拒否される可能性があります。

**対策の基本3原則：**
1. **AI生成コードは15行以内に分割**してコミットする
2. **人間による大幅な編集・改変**を加えて「共同著作物」にする
3. **AIツール名と生成日をコメントに明記**する（透明性の確保）

### 🎁 特典4: GCCポリシー対策チェックリスト

```
□ AI生成コードの行数を常にカウント（15行ルール）
□ 生成コードに必ず人間の編集を加える（最低30%変更）
□ コメントに「Generated by [AIツール名] on [日付]」を記入
□ コミットメッセージに「AI-assisted」と明記
□ ライセンス表示（MIT, Apache 2.0など）を確認
□ ポリシー改定を毎月チェック（GitHubの公式ブログ）
```

### 🎁 特典6: AIコード監査用チェックコマンド

```bash
# ファイルの行数を一括チェック
find . -name "*.css" -exec wc -l {} \; | sort -n

# 特定ディレクトリの15行以上のファイルをリストアップ
find ./src -name "*.css" -exec wc -l {} \; | awk '$1 > 15 {print}'

# AI生成コードのコメントを検索
grep -r "Generated by\|AI-assisted\|Copilot" ./src --include="*.css"

# Gitコミット履歴からAI生成コミットを確認
git log --oneline --grep="AI"
```
