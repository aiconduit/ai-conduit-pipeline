### 📌 ステップ1: agent-teamで自動レビューを起動

`.claude/skills/` に以下のスキルを追加して、**プランニング→実装→レビュー**を完全自動化します。

#### ✅ テクニック1: コードレビュースキル定義

```markdown
# .claude/skills/code-review.md

## 概要
プルリクエストのコードを自動レビューし、バグ・セキュリティ問題・改善点を抽出する。

## 実行手順
1. `git diff main...HEAD` で変更差分を取得
2. 以下の観点でレビューを実施:
   - 🔴 **重大バグ**: クラッシュ、データ損失、無限ループ
   - 🟠 **セキュリティ**: SQLインジェクション、XSS、認証バイパス
   - 🟡 **パフォーマンス**: N+1クエリ、メモリリーク
   - 🔵 **可読性**: 命名、コメント、複雑度
3. 重要度別にMarkdownテーブルでレポート出力
```

#### ✅ テクニック2: レビュー実行コマンド

```bash
# 1. コードレビューを実行
claude -p "スキルcode-reviewを実行して。重要度🔴の問題は修正まで提案して"

# 2. レビュー結果をPRコメントに自動投稿
claude -p "レビュー結果をgh pr comment 123 に投稿して"
```

### 📌 ステップ3: チートシートで即戦力化

#### ✅ テクニック5: レビュー重要度チェックリスト

| 重要度 | チェック項目 | 対応時間 |
|--------|-------------|---------|
| 🔴 **CRITICAL** | データ損失・クラッシュ・セキュリティホール | 即時修正 |
| 🟠 **HIGH** | 例外処理不足・非同期エラー未処理 | 30分以内 |
| 🟡 **MEDIUM** | 重複コード・命名改善・コメント不足 | 1時間以内 |
| 🔵 **LOW** | スタイル・フォーマット統一 | 修正任意 |

#### ✅ テクニック6: レビュー高速化プロンプト

```bash
# 3時間かかるレビューを10分に短縮する最強プロンプト
claude -p "
あなたはシニアエンジニアです。以下の観点でコードレビューしてください:

1. **バグ検出**: 境界値・null安全・レースコンディション
2. **セキュリティ**: OWASP Top 10に基づく脆弱性
3. **パフォーマンス**: 計算量・メモリ使用量

出力形式:
| 重要度 | ファイル | 行番号 | 問題点 | 修正提案 |
|-------|---------|--------|--------|---------|

修正提案は具体的なコード付きでお願いします。
"
```

#### ✅ テクニック7: レビュー時間短縮チェックリスト

```markdown
# レビュー前チェックリスト（30秒で完了）

- [ ] `git log --oneline -5` で変更概要を把握
- [ ] `git diff --stat` で影響範囲を確認
- [ ] テストコードの変更があるか確認
- [ ] TODO/FIXMEコメントが残っていないか検索
- [ ] 環境変数やAPIキーがハードコードされていないか
```
