# Claude Codeでコードレビューを読み取り専用で自動化 - 実践テンプレート

## この動画で学んだこと
Claude Codeのサブエージェント機能を使い、`disallowedTools`を設定することで、コードを変更せず読み取り専用でレビューする専用エージェントを簡単に作成できます。

## すぐに使えるテンプレート

### 1. レビュー専用サブエージェントの設定ファイル

`.claude/agents/reviewer.md` を作成します：

```markdown
---
name: reviewer
description: コードレビュー専用エージェント。読み取り専用で動作し、コードの変更は行いません。
disallowedTools: Write, Edit
---

あなたはシニアコードレビュアーです。以下の観点でコードをレビューしてください：

## レビューの観点

1. **バグの可能性**
   - 境界値のチェック
   - エラーハンドリングの欠如
   - リソースリークの有無

2. **セキュリティ**
   - インジェクション攻撃の脆弱性
   - 認証・認可の適切性
   - 機密情報のハードコーディング

3. **パフォーマンス**
   - 不要なループや再帰
   - N+1クエリ問題
   - メモリ使用の最適化

4. **コード品質**
   - 命名規則の一貫性
   - 重複コードの有無
   - コメントの適切性

5. **テスト可能性**
   - テスト可能な設計になっているか
   - 依存性の注入が適切か

## 出力形式

以下の形式でレビュー結果を報告してください：

### 問題点
- **重大度**: [高/中/低]
- **場所**: [ファイル名:行番号]
- **問題**: [具体的な問題の説明]
- **提案**: [改善案]

### 良い点
- 特に優れた実装や設計があれば記載

## 注意事項
- コードの変更は禁止されています
- 提案は具体的なコード例を含めてください
- 優先度の高い問題から順に報告してください
```

### 2. レビュー実行コマンド

```bash
# 特定のファイルをレビュー
claude --agent reviewer "src/app.ts をレビューしてください"

# 複数ファイルをレビュー
claude --agent reviewer "src/ ディレクトリ配下の全ファイルをレビューしてください"

# 変更差分のみをレビュー
claude --agent reviewer "git diff の変更内容をレビューしてください"

# 特定の観点に絞ってレビュー
claude --agent reviewer "セキュリティの観点で auth.ts をレビューしてください"
```

### 3. プロジェクト用のカスタムレビュー設定（オプション）

`.claude/agents/reviewer.md` にプロジェクト固有のルールを追加：

```markdown
---
name: reviewer
description: プロジェクト固有のルールに基づくコードレビュー
disallowedTools: Write, Edit
---

## プロジェクト固有のルール

### コーディング規約
- TypeScriptの型定義は必ず明示する
- 関数の長さは50行以内に保つ
- エラーメッセージは日本語で統一

### 禁止事項
- `any` 型の使用
- グローバル変数の使用
- ハードコーディングされた設定値

### 必須実装
- すべてのAPIエンドポイントにバリデーション
- 非同期処理にはエラーハンドリング
- ログ出力の標準化

## レビュープロセス
1. まず全体構造を把握
2. 上記のルールに基づいて詳細レビュー
3. 問題点を重要度順にリストアップ
4. 改善提案と具体的なコード例を提示
```

## 使い方

1. **設定ファイルの作成**
   - プロジェクト直下に `.claude/agents/` ディレクトリを作成
   - `reviewer.md` ファイルを上記のテンプレートで作成

2. **レビューの実行**
   - ターミナルで `claude --agent reviewer` コマンドを実行
   - レビュー対象のファイルやディレクトリを指定

3. **結果の確認**
   - レビュー結果は問題点と良い点に分けて表示
   - 重大度に基づいて優先的に対応

4. **カスタマイズ**
   - プロジェクトの規約に合わせてレビュー観点を追加
   - チームのルールを `reviewer.md` に追記

## よくある質問

**Q: レビュー中にコードが変更されることはありますか？**
A: いいえ。`disallowedTools: Write, Edit` の設定により、Claude Codeは読み取り専用で動作します。コードの変更やファイルの編集は一切行われません。

**Q: 複数のレビュー観点を同時に指定できますか？**
A: はい。プロンプトで「バグとセキュリティの観点でレビューしてください」のように複数の観点を指定できます。また、`reviewer.md` にデフォルトの観点を設定しておくことも可能です。

**Q: レビュー結果をファイルに保存できますか？**
A: はい。ターミナルのリダイレクションを使用して保存できます。例：`claude --agent reviewer "src/ をレビュー" > review_result.md`

**Q: チームメンバーと設定を共有するには？**
A: `.claude/agents/reviewer.md` をリポジトリにコミットすることで、チーム全体で同じレビュー設定を共有できます。

**Q: レビューの厳しさを調整できますか？**
A: はい。`reviewer.md` の説明文を編集することで調整できます。「重要な問題のみ報告」や「すべての指摘事項を報告」など、プロジェクトの状況に合わせて変更してください。
