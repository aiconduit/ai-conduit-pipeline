## <a id="1"></a>1️⃣ AIエージェントハーネス制御テンプレート

動画で解説した**検証→承認→実行**の3ステップを実装するPythonコードです。

```python
# ai_agent_harness.py
# 要件: Python 3.10+, anthropic, openai, google-generativeai

from dataclasses import dataclass
from typing import Any, Callable
import json

@dataclass
class AgentStep:
    name: str
    action: Callable
    requires_approval: bool = True

class AIAgentHarness:
    """検証・承認・実行を制御するAIエージェントハーネス"""
    
    def __init__(self, agent_func: Callable, validator_func: Callable):
        self.agent = agent_func
        self.validator = validator_func
        self.steps = []
        self.approval_log = []
        
    def add_step(self, step: AgentStep):
        self.steps.append(step)
        
    def run(self, task: str) -> dict:
        """タスクを検証→承認→実行の順で処理"""
        results = {}
        
        for step in self.steps:
            print(f"⚙️ Step: {step.name}")
            
            # ① 検証フェーズ
            validation = self.validator(step, task)
            if not validation["is_valid"]:
                print(f"❌ 検証失敗: {validation['reason']}")
                continue
            
            # ② 承認フェーズ
            if step.requires_approval:
                print(f"👤 承認が必要です: {step.name}")
                approval = input("承認しますか? (y/n): ")
                self.approval_log.append({"step": step.name, "approved": approval == "y"})
                if approval != "y":
                    print("⏭️ スキップされました")
                    continue
            
            # ③ 実行フェーズ
            result = step.action(task)
            results[step.name] = result
            print(f"✅ 完了: {step.name}")
            
        return results

# 使用例
def claude_agent(task):
    """Claude APIを呼び出すエージェント"""
    import anthropic
    client = anthropic.Anthropic()
    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=4096,
        messages=[{"role": "user", "content": task}]
    )
    return response.content[0].text

# バリデータ（検証ロジック）
def safety_validator(step, task):
    """コードインジェクションや危険な操作を検出"""
    dangerous_patterns = [
        "rm -rf", "DROP TABLE", "eval(", 
        "exec(", "sudo", "> /dev/sda"
    ]
    task_lower = task.lower()
    for pattern in dangerous_patterns:
        if pattern.lower() in task_lower:
            return {"is_valid": False, "reason": f"危険なパターン検出: {pattern}"}
    return {"is_valid": True, "reason": "OK"}

# ハーネスの実行
harness = AIAgentHarness(agent_func=claude_agent, validator_func=safety_validator)
harness.add_step(AgentStep("コード生成", claude_agent))
harness.add_step(AgentStep("テスト実行", lambda t: "pytest passed ✅"))
results = harness.run("Reactアプリのログイン機能を実装してください")
```

## <a id="2"></a>2️⃣ 検証ステップ用プロンプト

AIエージェントが生成したコードを検証するためのプロンプトです。

```
あなたはシニアコードレビュアーです。以下のAIが生成したコードを検証してください。

【検証項目】
1. セキュリティ: インジェクション、XSS、認証バイパスのリスクがないか
2. パフォーマンス: N+1問題、メモリリークがないか
3. 可読性: 命名規則、コメントの適切性
4. エラーハンドリング: 例外処理が適切か
5. テスト可能性: ユニットテストが書きやすい構造か

【検証対象コード】
{ここにコードを貼り付け}

【出力形式】
- リスクレベル: HIGH / MEDIUM / LOW
- 問題点: 行番号付きで列挙
- 修正提案: 具体的な修正コード
- 最終判定: PASS / FAIL
```
