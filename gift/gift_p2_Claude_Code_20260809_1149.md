# Claude Codeでコードレビュー自動化 - 実践テンプレート

## この動画で学んだこと
Claude Codeのサブエージェント機能を使い、`.claude/agents/reviewer.md`を作成することで、コードレビューを自動化できます。`disallowedTools`を設定することで、レビュアーがコードを変更できない安全な設計になっています。

## すぐに使えるテンプレート

### 1. レビュー用サブエージェント設定ファイル

`.claude/agents/reviewer.md` を作成します：

```markdown
---
name: reviewer
description: コードレビューを実行するエージェント。コードの品質、バグ、セキュリティ問題を検出します。
disallowedTools: Write, Edit
---

あなたはシニアコードレビュアーです。以下の観点でコードをレビューしてください：

## レビュー観点
1. **バグ検出**: 論理エラー、境界値の問題、例外処理の欠如
2. **セキュリティ**: インジェクション、認証・認可の脆弱性
3. **パフォーマンス**: 非効率なアルゴリズム、不要なリソース消費
4. **可読性**: 命名規則、コメントの適切さ、コードの構造
5. **テスト**: テストカバレッジの不足、テストの質

## レビューの進め方
1. 対象ファイルを読み込む
2. 上記の観点で問題を特定する
3. 問題を重要度（高/中/低）で分類する
4. 改善案を具体的に提示する

## 出力形式
- 問題点を重要度順にリストアップ
- 各問題にファイル名と行番号を明記
- 改善コード例を提示
- 最後に総合評価（GO/NO-GO）を判定
```

### 2. レビュー実行コマンド

```bash
# 特定のファイルをレビュー
claude --agent reviewer "src/app.ts をレビューしてください"

# 最近変更したファイルをレビュー
git diff --name-only HEAD~1 | xargs claude --agent reviewer "これらのファイルをレビューしてください"

# プルリクエスト全体をレビュー
claude --agent reviewer "mainブランチとの差分をレビューしてください"
```

### 3. カスタムレビュー指示の例

```markdown
# セキュリティ重視のレビュー指示
claude --agent reviewer "セキュリティ観点で重点的にレビューしてください。特に認証・認可、入力検証、SQLインジェクションに注意してください"

# パフォーマンス重視のレビュー指示
claude --agent reviewer "パフォーマンス問題に焦点を当ててレビューしてください。N+1クエリ、不要なループ、メモリリークに注意"
```

## 使い方

1. **セットアップ**: プロジェクトのルートに `.claude/agents/` ディレクトリを作成し、`reviewer.md` ファイルを配置します
2. **レビュー実行**: ターミナルで `claude --agent reviewer "レビュー対象"` を実行します
3. **カスタマイズ**: レビュー観点や出力形式をプロジェクトのニーズに合わせて編集します
4. **CI/CD統合**: プルリクエスト作成時に自動でレビューを実行するように設定できます

## よくある質問

**Q: レビューエージェントがコードを変更してしまうのを防げますか？**
A: はい、`disallowedTools: Write, Edit` を設定することで、レビュアーがファイルを書き換えることを防げます。レビューは読み取り専用で実行されます。

**Q: 複数のレビュー観点を設定できますか？**
A: 可能です。`description` フィールドに複数の観点をカンマ区切りで記述するか、プロンプト内で詳細な指示を追加できます。

**Q: レビュー結果をファイルに保存できますか？**
A: ターミナル出力をリダイレクトすることで保存できます。例: `claude --agent reviewer "レビューしてください" > review_result.md`

**Q: 既存のコードベース全体をレビューするには？**
A: `claude --agent reviewer "プロジェクト全体をレビューしてください"` と実行することで、コードベース全体を分析できます。ただし、大規模なプロジェクトでは時間がかかる場合があります。
