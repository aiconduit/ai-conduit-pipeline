## 🛠️ スキル1: Anthropic公式スキルのインストール

### インストールコマンド（3秒で完了）

```bash
# 公式スキルを一括インストール
claude install-skill anthropic/skills

# 特定のスキルのみインストール
claude install-skill anthropic/skills/code-review
claude install-skill anthropic/skills/documentation
claude install-skill anthropic/skills/testing
```

### インストール済みスキルの確認方法

```bash
claude list-skills
claude skill --help
```

## 🔍 スキル2: 自動コードレビュー完全ガイド

### 即効コードレビュープロンプト

```
あなたはシニアエンジニアです。以下のコードをレビューしてください。
観点:
1. セキュリティホール
2. パフォーマンス問題
3. 可読性・保守性
4. バグの可能性
5. 改善提案（具体的なコード付きで）

対象コード:
[コードを貼り付け]
```

### プロジェクト全体レビューコマンド

```bash
# 変更ファイルのみレビュー
claude review --diff

# 全ファイルをレビュー
claude review --all

# 特定ディレクトリをレビュー
claude review ./src/components
```

### 🔥 厳選！コードレビュー用プロンプト5選

| 用途 | プロンプト |
|------|-----------|
| **セキュリティ監査** | `このコードのOWASP Top 10に基づく脆弱性をチェックして` |
| **パフォーマンス最適化** | `Big O記法で計算量を分析し、改善案を3つ提示して` |
| **リファクタリング** | `SOLID原則に基づいてリファクタリング案を提示して` |
| **テスト戦略** | `この関数のユニットテストをJestで作成して` |
| **型安全性** | `TypeScriptの型定義をより厳密にする方法を提案して` |

## ⚠️ 注意ポイント

- Claude Codeは **Node.js 18以上** が必要です
- スキルの追加はプロジェクト単位で管理されます
- コードレビューは **1ファイル1000行以内** が精度の目安です
- 大量のコードをレビューする場合は分割して実行しましょう
