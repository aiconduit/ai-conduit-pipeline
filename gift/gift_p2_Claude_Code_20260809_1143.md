# Claude Codeで読み取り専用レビュー自動化 - 実践テンプレート

## この動画で学んだこと
Claude Codeのサブエージェント機能を使い、`disallowedTools`に`Write`と`Edit`を指定することで、コードを変更できない「読み取り専用」のコードレビュー担当エージェントを簡単に作成できます。

## すぐに使えるテンプレート

### 1. レビュー専用エージェントの設定ファイル

`.claude/agents/reviewer.md` を作成します：

```markdown
---
name: reviewer
description: コードレビュー専門エージェント。コードの品質・バグ・改善点を分析し、提案のみを行います。ファイルの変更は一切行いません。
disallowedTools: Write, Edit
---

あなたはシニアコードレビュアーです。以下の観点でコードをレビューしてください：

1. **バグの可能性**: 論理エラー、境界値、null/undefinedアクセス
2. **セキュリティ**: インジェクション、認証・認可の欠如、機密情報のハードコード
3. **パフォーマンス**: 不要なループ、メモリリーク、非効率なアルゴリズム
4. **可読性・保守性**: 命名、コメント、関数の長さ、重複コード
5. **ベストプラクティス**: 言語・フレームワークの標準的な慣習

## レビューの進め方

1. 対象ファイルを読み取り、全体像を把握する
2. 上記の観点で問題点を洗い出す
3. 各問題に対して、重要度（高/中/低）と修正提案を提示する
4. 最後に総合評価と優先度の高い改善ポイントをまとめる

## 重要な制約

- ファイルの書き込み・編集は禁止されています
- 提案は必ず「具体的なコード例」付きで行うこと
- 指摘は「問題点 → なぜ問題か → 修正案」の形式で報告すること
```

### 2. レビュー実行コマンド

```bash
# 特定のファイルをレビュー
claude --agent reviewer "src/app.ts をレビューしてください"

# 複数ファイルをレビュー
claude --agent reviewer "src/ ディレクトリ配下の全ファイルをレビューしてください"

# 変更差分をレビュー（Git使用時）
claude --agent reviewer "git diff の変更内容をレビューしてください"

# 特定の観点に絞ってレビュー
claude --agent reviewer "src/auth.ts のセキュリティ面を重点的にレビューしてください"
```

### 3. プロジェクト全体への適用例

`.claude/commands/review-all.md` を作成すると、スラッシュコマンドとして利用可能：

```markdown
---
description: プロジェクト全体をレビュー
---

プロジェクト全体のコードをレビューしてください。

対象:
- `src/` ディレクトリ配下の全ファイル
- テストコードは除外

出力形式:
- ファイルごとの問題点リスト
- 重要度別のサマリー
- 優先的に修正すべきトップ3
```

## 使い方

1. **エージェントファイルの作成**: プロジェクト直下に `.claude/agents/` ディレクトリを作成し、上記の `reviewer.md` を配置します
2. **エージェントの確認**: `claude --list-agents` コマンドで `reviewer` が表示されることを確認します
3. **レビューの実行**: `claude --agent reviewer "レビューしてほしい内容"` で実行します
4. **結果の確認**: エージェントが読み取り専用で分析し、改善提案を返します（ファイルは変更されません）

## よくある質問

**Q: `disallowedTools` に指定できるツールは他にありますか？**
A: 主なものとして `Write`, `Edit`, `Bash`, `Read` などがあります。`Write` と `Edit` を禁止することで読み取り専用になります。`Bash` も禁止すると完全に読み取りのみになります。

**Q: レビュー結果をファイルに保存したい場合はどうすればいいですか？**
A: レビューエージェントは書き込み禁止なので、結果をコピーして別途保存するか、`claude` コマンドの出力をリダイレクトしてください：
```bash
claude --agent reviewer "src/ をレビュー" > review-result.md
```

**Q: 複数のレビュー観点を持つエージェントを作れますか？**
A: 可能です。`.claude/agents/` 配下に `security-reviewer.md` や `performance-reviewer.md` など、目的別のエージェントを複数作成できます。

**Q: 既存のコードベースに適用する際の注意点は？**
A: 初回はファイル数が多いと時間がかかるため、ディレクトリ単位やファイル単位で段階的にレビューすることをおすすめします。
