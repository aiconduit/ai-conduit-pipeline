#### 🔹 プロンプト6: ヒューリスティック評価（専門家レビュー）
```
あなたは10年以上の経験を持つシニアUI/UXデザイナーです。以下に記載するUIデザインの詳細に対して、ニールセン博士の10のヒューリスティック原則に基づいて専門的な評価を行ってください。

【デザイン概要】
- 製品: 予約管理SaaS
- 画面: ダッシュボード
- レイアウト: 左サイドバー（ナビ）、上部検索バー、中央にカレンダー、右側に予約リスト
- 色: ブルー系基調、グレー背景
- ボタン: 新規予約ボタンは右上にプライマリー色

【評価してほしい点】
1. 各ヒューリスティック原則（1〜10）ごとに、このデザインの該当・非該当を判定
2. 特に問題がある項目は具体的な改善提案を提示
3. 優先度（高/中/低）を付けて修正すべき項目を3つ挙げてください
```

#### 🔹 プロンプト7: ユーザー視点でのシミュレーション
```
あなたは私のアプリの新規ユーザーです。以下に記載するUIデザインの説明を読み、実際にその画面を使うシミュレーションをしてください。

【画面仕様】
- 画面: 会員登録フォーム（4ステップ）
- ステップ1: 名前・メールアドレス入力
- ステップ2: パスワード設定（強度メーターあり）
- ステップ3: 興味・関心のタグ選択（最大5つ）
- ステップ4: 完了画面（サンクスページ）

【シミュレーション内容】
1. 各ステップを進みながら、あなたが感じるストレス・疑問点・迷いをリアルタイムで声に出してください
2. 途中で離脱したくなるポイントはどこか
3. 入力フォームのラベルやプレースホルダーの文言で改善すべき点
4. 最後に、全体の流れで気になった点を「改善必須」「あると良い」に分けてまとめてください

#### 🔹 プロンプト8: 競合比較分析
```
あなたはUIデザインアナリストです。以下の自社デザインと競合デザインを比較分析してください。

【自社のEコマースアプリUI】
- 商品一覧: 2カラムグリッド、写真上部、価格下部
- カート: 1ページ表示、送料計算はチェックアウト時
- チェックアウト: ゲスト購入可、3ステップ（情報→配送→支払い）

【競合A（楽天市場）】
- 商品一覧: 多数のオプション（並び替え、絞り込み）
- カート: ポイント・クーポン選択が複雑
- チェックアウト: 会員登録必須、多ステップ

【競合B（Amazon）】
- 商品一覧: リスト表示メイン、詳細情報多め
- カート: 1-Click注文機能あり
- チェックアウト: ワンクリック購入可能、迅速

【分析してほしいこと】
1. 自社のUIが競合と比べて優れている点・劣っている点を5つずつ
2. 最もコンバージョン率に影響するUI要素は何か
3. 自社がすぐに採用すべき改善施策を優先度順に3つ提案してください
```

#### 🔹 プロンプト9: CTAボタン文言のA/Bテスト作成
```
あなたはコンバージョン率最適化（CRO）の専門家です。以下の状況で、CTAボタンの文言バリエーションを10個作成してください。

【状況】
- 製品: プロジェクト管理ツールの無料トライアル登録
- 対象ユーザー: 25〜45歳のチームリーダー・マネージャー
- 現在のボタン文言: 「無料で始める」
- ボタンの場所: ランディングページのヒーローセクション
- デザイン: 青色の四角ボタン、白文字

【要件】
1. 各バリエーションは、行動を促す言葉＋価値提案を組み合わせてください
2. 短い文言（2〜4語）を5つ、中程度（5〜7語）を3つ、長め（8語以上）を2つ
3. 各バリエーションに、なぜその文言が効果的なのか分析コメントを1行添えてください
4. 心理的トリガー（希少性、社会的証明、損失回避など）を必ず1つ以上含めてください
```
