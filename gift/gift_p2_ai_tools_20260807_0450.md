## ✅ 1. OMX（Open Model Context）セットアップ

### インストール（1コマンド）
```bash
# macOS / Linux
curl -fsSL https://omx.sh/install | bash

# Windows (PowerShell)
irm https://omx.sh/install.ps1 | iex
```

### スキル追加（動画の核心！）
```bash
# プロジェクト専用スキルを追加
omx skill add typescript-react --template=tsx

# チーム共有スキルを追加
omx skill add git-commit-message --template=conventional

# 追加済みスキルの確認
omx skill list
```

### 実行コマンド
```bash
# スキルを指定してAI実行
omx run typescript-react "ログインフォームを作成"

# ファイルを指定して実行
omx run --file src/App.tsx "このコードをリファクタリング"
```

## ✅ 5. エージェント自動化の実践テンプレート

### GitHub Actions + AI 自動コードレビュー設定
```yaml
# .github/workflows/ai-review.yml
name: AI Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run AI Review
        run: |
          omx install
          omx run --file ${{ github.event.pull_request.diff_url }} \
            "このPRをレビューし、問題点をコメントしてください"
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
```
