# Claude CodeのdisallowedツールでAIレビューが読み取り専用になった - 実践テンプレート

## この動画で学んだこと
Claude Code の **サブエージェント設定ファイル**に `disallowed_tools` を記述すれば、AI に特定のツール（例: `file_write` や `shell`）を使わせず、レビューを **読み取り専用** にできることを学びました。

---

## すぐに使えるテンプレート
以下のファイルを **そのままコピー&ペースト** してプロジェクトのルートに置くだけで、レビュー用サブエージェントが作成できます。  

> **ファイル名**：`.claude/subagents/review_agent.yaml`  
> **拡張子は YAML（.yaml）** が推奨です。  

```yaml
# --------------------------------------------------------------
# review_agent.yaml
# Claude Code 用サブエージェント設定
# --------------------------------------------------------------
# このエージェントは「コードレビュー」専用です。
# 下記のツールはすべて禁止（disallowed）され、AI は読み取り専用に制限されます。
# --------------------------------------------------------------

# 1️⃣ エージェントの基本情報
name: review-agent               # 任意のエージェント名
description: "コードレビュー専用エージェント"  # 説明（任意）

# 2️⃣ 禁止したいツールを列挙
#   - file_write   : ファイル書き込み系コマンド全般
#   - shell        : 任意のシェルコマンド実行
#   - exec         : 外部プログラム実行
#   - network      : ネットワークアクセス（API 呼び出し等）
disallowed_tools:
  - file_write
  - shell
  - exec
  - network

# 3️⃣ 許可したいツール（必要に応じて追加）
#   例）read_only_file_read だけは許可したい場合は下記を有効化
# allowed_tools:
#   - read_only_file_read

# 4️⃣ デフォルトで有効になるツール（変更不要）
default_allowed_tools:
  - read_only_file_read   # 読み取りは常に許可

# 5️⃣ 追加設定（任意）
#   - max_output_tokens: 2000   # 出力トークン上限
#   - temperature: 0.0          # 生成のランダム性（0で決定的）

# --------------------------------------------------------------
# 使い方メモ（下部参照）
# --------------------------------------------------------------
```

## 使い方

1. **ファイルを作成**  
   ```bash
   # プロジェクトのルートに .claude ディレクトリが無い場合は作成
   mkdir -p .claude/subagents

   # テンプレートをそのまま貼り付けて保存
   cat > .claude/subagents/review_agent.yaml <<'EOF'
   # ← 上記テンプレート全体をここに貼り付け
   EOF
   ```

2. **Claude Code にサブエージェントを指定して起動**  
   ```bash
   # 例）現在のディレクトリのコードをレビューさせる
   claude code --sub-agent .claude/subagents/review_agent.yaml .
   ```

3. **レビュー結果を確認**  
   - AI は `file_write`・`shell` などの禁止ツールを呼び出そうとするとエラーを返し、**読み取り専用** のみが許可されます。  
   - 必要に応じて `disallowed_tools` リストにツールを追加・削除してカスタマイズしてください。

4. **サブエージェントを他のタスクでも再利用**  
   - `review_agent.yaml` をコピーして名前を変え、`allowed_tools` を調整すれば、**テスト実行エージェント**や**ドキュメント生成エージェント**としても使えます。

## よくある質問

**Q1. 「disallowed_tools」に入れたツールは本当に実行できなくなるの？**  
A: はい。Claude Code はサブエージェントの設定を厳格にチェックし、リストに含まれるツールは実行時に即座にブロックします。エラーメッセージに「Tool is disallowed」と表示されます。

**Q2. それでもファイルを書き換えてしまうケースはある？**  
A: 現在の実装では `file_write` が禁止されていれば、`open(..., "w")` や `os.makedirs` などの書き込み系 API はすべてエラーになります。唯一の例外は **読み取り専用** のファイル操作（`read_only_file_read`）だけです。

**Q3. ネットワークアクセスだけ禁止したい場合はどうすれば？**  
A: `disallowed_tools` に `network` だけを書き込み、他のツールはリストから除外すれば OKです
